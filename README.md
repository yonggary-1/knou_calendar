# Knou calendar

한국방송통신대학교(KNOU) MyKNOU에 흩어져 있는 **출석수업·중간평가·기말평가·형성평가 일정**을 구글 캘린더의 전용 캘린더로 자동으로 옮겨 주는 브라우저 확장입니다. 출석수업 장소를 바꾸거나 일정이 바뀌어도 바뀐 부분만 다시 반영됩니다. 언제, 어디서, 무엇을 해야 하는지를 캘린더 하나와 확장 팝업으로 챙길 수 있게 하려고 만들었습니다.

> 방통대와 관계없는 **개인이 만든 비공식 도구**입니다.

## 주요 기능

- **자동 등록**: MyKNOU 대시보드에서 수강 과목 일정을 읽어 구글 캘린더 "방통대 학사일정" 캘린더에 넣습니다.
  - 출석수업: 수업 시간과 장소. 장소는 `한국방송통신대학교 서울남부학습센터`처럼 구글 지도가 찾을 수 있는 정식 명칭으로 바꿉니다.
  - 과제형 평가: 제출기간(종일 일정)과 마감 일정, 그리고 알림.
  - 시험형 평가: 시험 시간. 날짜가 공지되면 다음 동기화 때 추가됩니다.
  - 형성평가: 학습 기간과 마감.
- **변경 반영**: 캠퍼스 변경, 일정 변경, 수강 취소를 감지해 해당 과목의 일정만 교체하거나 삭제합니다. 반영 전에 미리보기로 확인합니다.
- **남은 일정 보기**: 확장 아이콘을 누르면 과목별로 남은 할 일과 D-day가 보이고, 각 항목에서 해당 방통대 페이지로 바로 갈 수 있습니다.
- **안전장치**
  - 직접 만든 일정과 지난 학기 일정은 건드리지 않습니다.
  - 과목을 하나도 못 읽었을 때는 지우기 전에 따로 확인을 받습니다.
  - 방통대 세션이 끊기면 로그인 후 자동으로 이어서 진행합니다.

## 실행 환경

- **Chromium 계열 116 이상**: Chrome, Edge, 웨일, 오페라 (Windows·macOS·Linux 데스크톱)
- **Firefox 140 이상**
- MyKNOU(m.knou.ac.kr) 로그인 계정과 구글 계정
- 모바일 브라우저는 지원하지 않습니다. 등록된 일정은 휴대폰의 구글 캘린더 앱에서 그대로 볼 수 있습니다.

## 설치

### Chrome · Edge · 웨일 · 오페라

1. [Releases](https://github.com/yonggary-1/knou_calendar/releases)에서 `knou_calendar_chromium.zip`을 받아 압축을 풉니다. 예: `C:\Tools\knou_calendar_chromium`
   - 확장이 이 폴더에서 실행되므로 지우지 마세요.
2. 주소창에 `chrome://extensions`를 입력합니다. Edge는 `edge://extensions`, 웨일은 `whale://extensions`, 오페라는 `opera://extensions`입니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램 로드**를 누르고 압축을 푼 폴더를 선택합니다.

### Firefox

`knou_calendar_firefox.zip`은 Mozilla 서명을 받기 위한 제출용 파일입니다. 서명 방법은 [개발자 문서](docs/DEVELOPER.md#파이어폭스-배포)를 참고하세요.

## 사용법

1. MyKNOU(m.knou.ac.kr)에 로그인합니다.
2. 확장 아이콘 → **동기화 확인**을 누릅니다.
3. 처음 한 번 구글 계정 선택과 권한 동의 창이 뜹니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급(또는 Continue) → Knou calendar로 이동**을 누릅니다.
   - 권한 화면에서 **캘린더 항목을 반드시 체크**하세요.
4. 미리보기 목록을 확인하고 **반영**을 누릅니다.

이후로는 일정이 바뀌었을 때 **동기화 확인 → 반영**만 하면 됩니다.

### 구글 연결 관련 안내

- 이 확장의 구글 앱은 현재 **테스트 단계**입니다. 개발자가 테스트 사용자로 등록한 Gmail만 연결할 수 있습니다. 등록되지 않은 계정은 `access_denied` 오류가 납니다. 사용하려면 개발자에게 등록을 요청하거나, [자신의 OAuth 클라이언트](docs/DEVELOPER.md#자신의-구글-oauth-클라이언트-쓰기)를 만들어 쓰세요.
- 권한 범위는 **이 확장이 만든 캘린더만**입니다. 다른 캘린더의 일정은 읽거나 바꿀 수 없습니다.

## 개인정보

- 방통대에서 읽은 정보는 **사용자의 브라우저와 본인 구글 캘린더에만** 저장됩니다. 별도의 서버로 보내지 않습니다.
- 캘린더 일정에는 과목명, 시간, 장소, 담당교수 연락처(방통대 페이지에 공개된 것)만 들어갑니다.
- 설정의 **버그 리포트 저장** 파일에는 이름·학번·이메일·과목 목록이 들어가지 않습니다.

## 문제가 생기면

설정(팝업의 톱니바퀴) → **버그 리포트 저장**으로 받은 `knou_calendar_<버전>_bug_report_<시각>.txt` 파일을 이슈에 첨부해 주세요.
