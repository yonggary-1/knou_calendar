# Knou calendar

한국방송통신대학교(KNOU) MyKNOU에 흩어져 있는 **출석수업·중간평가·기말평가·형성평가 일정**을 구글 캘린더의 전용 캘린더로 자동으로 옮겨 주는 브라우저 확장입니다. 출석수업 장소를 바꾸거나 일정이 바뀌어도 바뀐 부분만 다시 반영됩니다. 언제, 어디서, 무엇을 해야 하는지를 캘린더 하나와 확장 팝업으로 챙길 수 있게 하려고 만들었습니다.

> 방통대와 관계없는 **개인이 만든 비공식 도구**입니다.

## 주요 기능

- **자동 등록**: MyKNOU 대시보드에서 수강 과목 일정을 읽어 구글 캘린더 "방통대 학사일정" 캘린더에 넣습니다.
  - 출석수업: 수업 시간과 장소. 장소는 `한국방송통신대학교 서울남부학습센터`처럼 구글 지도가 찾을 수 있는 정식 명칭으로 바꿉니다.
  - 과제형 평가: 제출기간(종일 일정)과 마감 일정, 그리고 알림.
  - 시험형 평가: 시험 시간. 날짜가 공지되면 다음 동기화 때 추가됩니다.
  - 형성평가: 학습 기간과 마감.
- **변경 반영**: 캠퍼스 변경, 일정 변경, 수강 취소를 감지해 해당 과목의 일정만 교체하거나 삭제합니다. 반영 전에 미리보기로 확인합니다.
- **과제 메모와 위젯 (선택)**: 과목별 레포트 주제·시험 범위를 Dropbox의 `knou_scope.txt`에 적어 두면, 확장 편집기·아이패드 위젯·메모장 어디서든 고칠 수 있고 구글 캘린더 일정 설명란에도 들어갑니다. 동기화할 때마다 남은 일정과 메모를 위젯용으로 내보내고, 위젯 스크립트(KnouWidget)도 Dropbox에 넣어 둡니다.
- **남은 일정 보기**: 확장 아이콘을 누르면 과목별로 남은 할 일과 D-day가 보이고, 각 항목에서 해당 방통대 페이지로 바로 갈 수 있습니다.
- **안전장치**
  - 직접 만든 일정과 지난 학기 일정은 건드리지 않습니다.
  - 과목을 하나도 못 읽었을 때는 지우기 전에 따로 확인을 받습니다.
  - 방통대 세션이 끊기면 로그인 후 자동으로 이어서 진행합니다.

## 실행 환경

- **Chromium 계열 116 이상**: Chrome, Edge, 웨일, 오페라 (Windows·macOS·Linux 데스크톱)
- **Firefox 140 이상**
- MyKNOU(m.knou.ac.kr) 로그인 계정과 구글 계정
- 모바일 브라우저는 지원하지 않습니다. 등록된 일정은 휴대폰의 구글 캘린더 앱에서 그대로 볼 수 있습니다.

## 설치

### Chrome · Edge · 웨일 · 오페라

1. [Releases](https://github.com/yonggary-1/knou_calendar/releases)에서 `knou_calendar_chromium.zip`을 받아 원하는 곳에 압축을 풉니다. 예를 들어 `C:\Tools`에 풀면 `C:\Tools\knou_calendar_chromium` 폴더가 생깁니다.
   - 확장이 이 폴더에서 실행되므로 지우지 마세요.
2. 주소창에 `chrome://extensions`를 입력합니다. Edge는 `edge://extensions`, 웨일은 `whale://extensions`, 오페라는 `opera://extensions`입니다.
3. **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램 로드**를 누르고 `knou_calendar_chromium` 폴더를 선택합니다. 업데이트할 때는 같은 곳에 덮어쓴 뒤 확장 관리 화면에서 새로고침(↻)을 누르면 됩니다.

### Firefox

`knou_calendar_firefox.zip`은 Mozilla 서명을 받기 위한 제출용 파일입니다. 서명 방법은 [개발자 문서](docs/DEVELOPER.md#파이어폭스-배포)를 참고하세요.

## 사용법

1. MyKNOU(m.knou.ac.kr)에 로그인합니다.
2. 확장 아이콘 → **동기화 확인**을 누릅니다.
3. 처음 한 번 구글 계정 선택과 권한 동의 창이 뜹니다.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급(또는 Continue) → Knou calendar로 이동**을 누릅니다.
   - 권한 화면에서 **캘린더 항목을 반드시 체크**하세요.
4. 미리보기 목록을 확인하고 **반영**을 누릅니다.

이후로는 일정이 바뀌었을 때 **동기화 확인 → 반영**만 하면 됩니다.

### 구글 연결 관련 안내

- 이 확장의 구글 앱은 현재 **테스트 단계**입니다. 개발자가 테스트 사용자로 등록한 Gmail만 연결할 수 있습니다. 등록되지 않은 계정은 `access_denied` 오류가 납니다. 사용하려면 개발자에게 등록을 요청하거나, [자신의 OAuth 클라이언트](docs/DEVELOPER.md#자신의-구글-oauth-클라이언트-쓰기)를 만들어 쓰세요.
- 권한 범위는 **이 확장이 만든 캘린더만**입니다. 다른 캘린더의 일정은 읽거나 바꿀 수 없습니다.

### Dropbox 내보내기와 위젯 (선택)

아이패드·아이폰 위젯(KnouWidget)에서 일정과 과제 메모를 함께 보고 싶을 때만 씁니다. 쓰지 않으면 아무것도 바뀌지 않습니다.

1. 팝업의 **Dropbox** 줄에서 **연결**을 누릅니다. 설정 → **4. Dropbox 내보내기**의 **연결**도 같습니다.
2. Dropbox 로그인 창에서 **허용**을 누릅니다. 확장에 Dropbox 앱 키가 내장되어 있어 따로 입력할 것은 없습니다.

연결하면 팝업의 버튼이 **동기화 확인 & Dropbox 내보내기**로 바뀝니다. 이 버튼 하나로 캘린더 동기화와 내보내기를 함께 합니다. 내보내기가 실패하면 Dropbox 줄의 점이 빨갛게 바뀌고, 버튼을 다시 누르면 다시 시도합니다. Dropbox를 쓰지 않는다면 팝업의 **사용 안 함**을 누르세요. 나중에 설정 → 4번에서 연결하면 다시 나타납니다.

파일은 Dropbox의 `Apps › KnouWidget` 폴더에 있습니다. PC에 Dropbox 프로그램이 있으면 `%USERPROFILE%\Dropbox\Apps\KnouWidget\`에서도 볼 수 있습니다.

| 파일 | 내용 | 누가 고치나 |
| --- | --- | --- |
| `knou_scope.txt` | **과제 메모** — 과목별 중간평가·기말평가 내용과 과목 메모 | 사용자 (팝업의 📝 과제 메모, 위젯, 메모장). 확장은 파일이 없을 때만 양식을 만듦 |
| `knou_agenda.json` | 팝업의 남은 일정 + 과제 메모를 해석한 `notes` | 확장이 덮어씀 (동기화할 때, 과제 메모를 저장할 때) |
| `KnouWidget.js` | 위젯 스크립트 | 확장이 올림 (없거나 버전이 다를 때만) |

### 과제 메모

팝업 아래의 **📝 과제 메모**를 누르면 큰 편집 화면이 열립니다. 과목마다 **중간평가 / 기말평가 / 과목 메모** 칸에 서식 없는 글자로 적고 **저장**(또는 `Ctrl+S`)을 누르세요.

- 저장하면 위젯에 바로 반영됩니다. 구글 캘린더 일정 설명란에는 **다음 동기화 때** 들어갑니다.
  - **평가 내용**은 그 평가의 **제출기간** 일정에 들어갑니다(시험형은 시험 일정). 마감 일정에는 넣지 않습니다. 단, 제출기간 일정이 없을 때(설정에서 껐거나 하루짜리 기간)는 마감 일정에 넣습니다.
  - **과목 메모**는 그 과목의 일정 전부(출석수업 포함)에 들어갑니다.
  - 메모만 바뀌면 일정을 다시 만들지 않고 설명란만 고칩니다. 알림이 다시 울리지 않습니다.
- 위젯이나 메모장에서 같은 파일을 고쳐도 됩니다. 편집하는 사이에 다른 곳에서 먼저 저장했다면 덮어쓰지 않고 알려 주며, **새 내용 불러오고 내 변경 다시 채우기**로 양쪽 내용을 모두 살릴 수 있습니다.
- 메모장으로 직접 고칠 때의 형식입니다. 과목명 줄은 MyKNOU 과목명과 같아야 하며 띄어쓰기는 무시합니다. 첫 과목명 위의 줄(머리말)은 위젯에 나오지 않습니다.

  ```
  2026-2학기 과제 메모 — 첫 과목명 위에 적은 내용은 위젯에 나오지 않습니다.

  인간과사회
  교재 2026 개정판 사용            ← 과목 메모 (과목명 바로 아래)
  중간평가:
  기말평가: 교재 3장의 사회 계층 이론으로 사례 분석
  A4 3쪽 내외, 참고문헌 2개 이상    ← 여러 줄 가능
  ```

- 학기가 바뀌면 옛 파일을 `archive\knou_scope_<학기>.txt`로 옮기고 새 양식을 만듭니다. 학기는 **머리말 첫 줄의 `2026-2학기`**로 판단합니다. 머리말을 지우면 확장은 그 파일을 사용자 것으로 보고 옮기지 않습니다.
- 1.5.0까지 쓰던 `knou_scope.json`은 더 이상 만들지 않습니다. 있던 파일은 지우지 않으며, `knou_scope.txt`가 없을 때 편집기가 그 내용으로 시작합니다.

### 아이패드·아이폰 위젯 설치 (처음 한 번)

1. App Store에서 **Scriptable**을 설치하고 한 번 엽니다.
2. 위의 Dropbox 연결을 하고 한 번 동기화합니다. 확장이 `Apps › KnouWidget`에 `KnouWidget.js`를 넣어 둡니다.
3. **파일** 앱 → **Dropbox** → **Apps › KnouWidget** → `KnouWidget.js`를 길게 눌러 **복사**합니다.
4. **iCloud Drive › Scriptable**에 **붙여넣기**합니다. 이름은 `KnouWidget.js` 그대로 둡니다(대소문자 구분).
5. Scriptable에서 **KnouWidget**을 한 번 실행해 Dropbox를 연결하고, 홈 화면에 Scriptable 위젯을 추가해 스크립트로 KnouWidget을 고릅니다.

Scriptable 폴더에는 다른 앱이 파일을 넣을 수 없어서 3~4번 복사는 직접 해야 합니다. 위젯 v1.1.0부터는 Scriptable에서 KnouWidget을 실행할 때 확장이 올려 둔 새 버전으로 **스스로 바뀌므로**, 복사는 처음 한 번만 하면 됩니다(v1.0.0을 쓰고 있었다면 v1.1.0으로 한 번 더). 위젯 스크립트는 [릴리즈](https://github.com/yonggary-1/knou_calendar/releases/latest/download/KnouWidget.js)에서도 받을 수 있습니다.

확장의 Dropbox 앱은 아직 **개발 단계**라 연결할 수 있는 사용자 수에 제한이 있습니다. 연결이 거부되면 [직접 만든 Dropbox 앱](docs/DEVELOPER.md)의 키를 설정 → 고급에 넣어 쓸 수 있습니다.

## 개인정보

- 방통대에서 읽은 정보는 **사용자의 브라우저와 본인 구글 캘린더에만** 저장됩니다. Dropbox 내보내기를 켜면 본인 Dropbox 앱 폴더에도 저장됩니다. 그 밖의 서버로는 보내지 않습니다.
- Dropbox 앱 폴더 권한은 그 폴더 하나에만 접근할 수 있고, 다른 Dropbox 파일은 읽지 못합니다.
- 캘린더 일정에는 과목명, 시간, 장소, 담당교수 연락처(방통대 페이지에 공개된 것)만 들어갑니다.
- 설정의 **버그 리포트 저장** 파일에는 이름·학번·이메일·과목 목록이 들어가지 않습니다.

## 문제가 생기면

설정(팝업의 톱니바퀴) → **버그 리포트 저장**으로 받은 `knou_calendar_<버전>_bug_report_<시각>.txt` 파일을 이슈에 첨부해 주세요.
