## Knou calendar v1.6.3 — Widget v1.1.2

The extension behaves the same as 1.6.2. Only the bundled iPad/iPhone widget script changed, to **KnouWidget v1.1.2**.

### Widget v1.1.2
- **When you pick a course to view large, assignment notes now fill the card by adjusting the font size automatically.** (Widget Parameter `1`, `인간과사회`, etc., on large and extra-large widgets.) Previously, a long paragraph that wrapped on screen was cut off with "…" even when there was empty space below.
- The course grid (a) also divides note lines by the number of wrapped lines on screen.

### How to update
1. Update the extension to 1.6.3 (extract the Chromium zip over the same place and press reload ↻ on the extensions page) and sync once. The extension uploads widget v1.1.2 to Dropbox.
2. Run KnouWidget once in Scriptable on your iPad; widget v1.1.0 or later replaces itself with v1.1.2. If you are still on v1.0.0, copy it once more from the Files app.

### Assets
- `knou_calendar_chromium.zip`: for Chrome, Edge, Whale, and Opera.
- `knou_calendar_firefox.zip`: package for Mozilla signing (Firefox).
- `KnouWidget.js`: the iPad/iPhone Scriptable widget script (v1.1.2).
